# ROADMAP TEMPLATE

This is a template, not approval to implement every item. The human-approved design and current milestone take precedence.

## Milestone 0 — Baseline
Confirm engine/version, target platform, repository structure, build/run/test commands.
Acceptance: baseline can be reproduced and is documented with evidence.

## Milestone 1 — Representative core loop
Base/building upgrade → resource production/spending → fleet creation → battle simulation/visualization → valid rewards → spend rewards on progression.
Include save/load where required by the approved design.
Acceptance: connected end-to-end loop is tested and playable in the target runtime.

## Milestone 2 — Stability and balance
Cross-system integration tests, economy/progression checks, bug/regression fixes, representative mobile performance test.

## Milestone 3 — Content expansion
Add approved buildings, ships, enemy roles, sectors, missions, and bosses. Each item must have a distinct gameplay purpose and reuse validated systems.

## Milestone 4 — Player validation
Test comprehension, fun, friction, and reasons to return; make changes based on evidence.

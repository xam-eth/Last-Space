# Mandatory AI agent instructions

Before every development task, inspect the actual repository and read `AI_GOVERNANCE.md`, `PROJECT_STATUS.md`, `ROADMAP.md`, and the current approved milestone plan if present. Do not rely on chat memory alone.

`AI_GOVERNANCE.md` is mandatory for implementation, debugging, QA, refactoring, asset generation, and reporting. Code generation is not proof of completion. Never invent test results, logs, screenshots, performance, or repository state.

Every meaningful session must advance a verified game capability or isolate a concrete blocker that enables the next implementation step. Do not repeat audits, tests, planning, or documentation without relevant changes, new evidence, or a decision the result could change. Do not silently change scope, acceptance criteria, engine, renderer, architecture, asset format, or backend strategy.

The human developer is the final decision-maker. End each meaningful session with the report format in `AI_GOVERNANCE.md`.
